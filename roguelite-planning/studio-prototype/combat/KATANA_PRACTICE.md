# Katana practice rig

Workspace.KatanaPractice contains a KatanaBlade cloned from the user-sized combat template. HumanoidRootPart.KatanaGrip is a Motor6D connecting the root to the sword, with C1 locating the animation joint at the measured handle pivot. Root is anchored; sword is unanchored, massless, noncolliding. No animation poses were authored. This is an editor practice copy; it does not replace runtime scripted combat.
