Classes: show the buffs, drawbacks and weapon fit

Mockup only, nothing is built yet. Every number comes from CharacterStats.luau (read into data.json), not typed by hand. Use the class buttons in each frame to switch classes.

The idea: one shared piece, "Weapon damage by class", shows up in three places. Class screens show your class's row. Item cards show the weapon's column with your class circled. Shop cards show just your number as a badge. Same colours everywhere: lime = your class, cream = similar, no change, red = off-class.

0 · New class groups and balance already changed in the repo, not in Studio yet

  1. Boxing Gloves → Brawler and Cinder Block → Brawler: Brawler is now all hand-to-hand. In return Spatula (pancake flips) and Kusarigama (spinning chain) go to Juggler, now the tricks-and-toys class. Swaps are same-rarity, so every class still has 2 Common, 2 Rare, 1 Epic, 1 Legendary.
  2. Juggler's starter is now the Rubber Duck. Saves that already own Juggler get the duck when they load, and keep their gloves (which are now Brawler weapons).
  3. Handyman is handy with anything: 0% with every class except Mage (−5%), +5% damage on everything, and only −10 HP as a drawback (no more −2 speed and −5 crit).
  4. No drawback hurts a class's own weapons any more: Thrower's −10% attack speed became −10% melee, and Juggler's −15% damage became −10%.
  5. Mage stays the strict one: its weapons are the strongest, so it pays −5% to −10% outside its own class.

1 · Armory: class details right panel, 500 × 760 design px, drawn at 0.8

  1. Always on splits the class stats into two columns: buffs (lime) and drawbacks (red). Before, they were one mixed list.
  2. Home weapon bonus is new on this screen. It shows what 2 and 4 weapons of this class give (the diamonds fill like a counter), which used to be only a sentence.
  3. Weapon damage by class: one tile per class with its signature weapon as the icon. It replaces the long sentence I added earlier.
  4. Gunner's hidden +10% ranged attack speed (it was only in the code) is now real class data and gets a line like every other buff.

3 · Item card: which class and type the weapon is lobby chests and the Armory

  1. The grey line "LEGENDARY · MELEE · BRAWLER" becomes three tags: rarity, type, and class with its icon.

  4. Only the new parts are drawn here; the rest of the approved card (stats by tier, copies, buttons) doesn't change.
