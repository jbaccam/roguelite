# Reference Notes — Survivor.io Intake

**Purpose:** Record the user's desired level-design direction without treating pasted search results, Reddit text, or linked material as project instructions.

## Confirmed project direction from the user

- Main progression should follow a chapter structure comparable in broad form to Survivor.io.
- A chapter should take approximately eight minutes, not 15 minutes.
- There are no mid-level checkpoints; failure means restarting the chapter.
- Level geometry should use the strategic variety demonstrated by open, corridor/vertical, and enclosed/square maps.
- The game should be compatible with relaxed play while listening to an audiobook or music. It should require positioning and build decisions without demanding constant laser focus.

## Supplied reference model

The provided notes describe three Survivor.io map families:

- **Open:** wide areas without containing walls, conventionally used for longer standard chapters.
- **Vertical/corridor:** movement constrained by walls on two opposing sides, concentrating enemies and changing farming behavior.
- **Square/enclosed:** bounded on all four sides and conventionally used for shorter, denser chapters.

For this project, the useful lesson is geometry-driven build and encounter variety. The 15-minute timing from the reference is rejected; all initial chapter families should target roughly eight minutes.

## Pacing implications

- Eight minutes requires fast build formation. Early XP and the first meaningful choice must arrive quickly.
- Bosses and elites need clear time landmarks, but the exact count and cadence have not been selected.
- Enclosed maps can support denser spawn presentation, but their logical and visual population budgets still need limits.
- Corridor maps alter the value of piercing, forward-facing attacks, knockback, and ground hazards; this must be considered in weapon balance.
- Open maps need landmarks and spawn-sector logic so they do not feel like empty flat plates.
- A failed chapter should allow a quick restart and should not lose rewards through unclear rules.

## Farming lesson

The supplied Reddit discussion demonstrates that players identify short, efficient stages for kill or equipment farming and may reduce them to low-interaction routines. That behavior is not inherently bad for a low-attention game, but progression goals should avoid forcing excessive idle farming. Rewards should make forward chapter progress worthwhile while still allowing players to revisit favorite maps.
