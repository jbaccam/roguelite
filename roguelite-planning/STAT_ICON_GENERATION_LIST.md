# Level-up upgrade icons

Only these 16 primary stats appear as selectable level-up upgrades. Each uses its own image across all rarity tiers. Shop item art is separate, including Fridge Magnet. Secondary stats shown in the stats panel are improved by items, weapons, and other effects; they do not need level-up upgrade icons.

| Upgrade | Image file | Simple symbol |
|---|---|---|
| Vitality / Max HP | `MaxHP.png` | Red heart |
| Damage | `Damage.png` | Orange fist |
| Attack Speed | `AttackSpeed.png` | Three pale silver diagonal slash streaks |
| Armor | `Armor.png` | Steel-blue shield |
| Dodge | `Dodge.png` | Pale teal feather |
| Regeneration | `Regeneration.png` | Green sprout |
| Life Steal | `LifeSteal.png` | Red blood drop |
| Critical Chance | `CritChance.png` | Plain red crosshair |
| Melee Damage | `MeleeDamage.png` | Silver blade mark |
| Ranged Damage | `RangedDamage.png` | Blue arrowhead |
| Elemental Damage | `ElementalDamage.png` | Orange flame |
| Utility Power | `UtilityPower.png` | Brass gear |
| Movement Speed | `MoveSpeed.png` | Light-blue wing |
| Pickup Radius | `PickupRadius.png` | U-shaped magnet with teal tips |
| Luck | `Luck.png` | Four-leaf clover |
| Attack Range | `AttackRange.png` | Violet concentric range rings |

The earlier orange three-point burst for Damage was ambiguous and has been discarded. Life Steal uses the red drop selected by the user. The pickup-radius magnet is a distinct stat pictogram; the shop Fridge Magnet is a flat blue enamel tile with a sun emblem.

Art: transparent PNG, centered single low-poly symbol with a dark outline, readable at card size. No action scene, extra prop, text, or rarity border.
