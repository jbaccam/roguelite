# Medusas Head

Sculpted olive stone face, green almond eyes, five open serpent mouths with upper and lower fangs, seven curved serpent locks and jeweled handle.

Reference: ChatGPT Image Sep 17, 2026, 03_24_52 PM (5).png (user-provided generated art; copied unmodified as Reference.png).

Rebuild using Blender in background mode with batches/magic/build_magic.py -- 34.

Separate named mesh components; one portable face-color atlas, packed in Model.blend and embedded in FBX/GLB. Rear details inferred from the visible design. Decorative closed components intentionally intersect. Static components can be merged on import if desired.

Preview.png and Alternate.png are actual Blender renders. validation.json records geometry checks and independent FBX/GLB reimport mesh/triangle counts. Roblox Studio import, final game scale, attachments, collision and gameplay behavior have not been tested.
