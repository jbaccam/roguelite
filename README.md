# Wavebreaker: Survive the Horde

A Roblox wave-survival roguelite: pick a class, your weapons fight on their own, survive 20 waves of
mobs and a boss on each map, spend shards in the shop between waves, and keep going in Endless.
Studio place `roguelite` (ID 107877054949326).

- Design and plans: [roguelite-planning/](roguelite-planning/) — start at
  [CURRENT_GAME_STRUCTURE.md](roguelite-planning/CURRENT_GAME_STRUCTURE.md).
- Game code: [roguelite-planning/studio-prototype/](roguelite-planning/studio-prototype/README.md).
- Build: `rojo build roguelite-planning/studio-prototype/combat/default.project.json -o build/RogueliteKatanaCombat.rbxlx`
- Servers: one lobby server, one private match server per party
  ([LOBBY_AND_MATCH_SERVERS.md](roguelite-planning/LOBBY_AND_MATCH_SERVERS.md)).

This repo was renamed from `partyati` on 2026-10-02; the other games that used to live here
(Copy The Scene, the brainrot prototype, the facility blockout, house optimization) were removed.
